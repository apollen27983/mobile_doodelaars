# MobileProject-Doodelaars

## Overview
**MobileProject-Doodelaars** is a mobile game that challenges players to survive by jumping from platform to platform while utilizing different sensors and mechanics to navigate the environment. The game incorporates teleportation mechanics and makes use of various mobile device features to enhance gameplay.

## Features
- **Platform Jumping Gameplay**: Players must continuously jump from one platform to another to survive.
- **Screen Edge Teleportation**: Moving off the left side of the screen teleports the player to the right side, and vice versa.
- **Sensor-Based Controls**:
  - **Touch Input**: Used for controlling jumps or interactions.
  - **Gyroscope Sensor**: Enables tilt-based movement mechanics.
  - **Vibration Feedback**: Provides haptic feedback during gameplay events.
- **Shader Effects**: Utilizes experimental beta-version shaders for enhanced visual effects.
- **Audio Design**:
  - Background music and ambient sounds enhance immersion.
  - Custom sound effects designed for gameplay interactions.
- **3D Models**: Predownloaded open-source models are integrated to create the game environment.

## Dependencies
This project relies on several external assets and technologies:
- **Open-source 3D models**: Used for characters, platforms, and environmental elements.
- **Experimental Shaders**: Some visual effects depend on shaders that are still in beta development.
- **Mobile Sensors**: The game utilizes built-in smartphone sensors for an interactive experience.
